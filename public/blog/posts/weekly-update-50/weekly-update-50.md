<img src="/blog/emoji/foxruler-925626255267749968.webp" alt="foxruler" class="discord-emoji" /> **WHAT'S THE FOX DOIN'??? AGAIN!** While we were blinking, @Deleted User added support for hand tracking for SlimeVR <img src="/blog/emoji/nya_a-847203539352551544.webp" alt="nya_a" class="discord-emoji" /> This was always the plan, 10+6 set should allow it - hand tracking without controllers (only position, no fingers ofc, use LucidVR for fingers). But it wasn't implemented yet. Until now... You will need a lot of trackers for this - chest, upper arm, lower arm, hand. And precision is of course worse than controller tracking, but hey if it's good enough for Rokoko, it's good enough for us lol! This will be in the next server build, or you can just download the last main if you have enough trackers.
