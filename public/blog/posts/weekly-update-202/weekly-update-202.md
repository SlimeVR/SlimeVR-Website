## Butterfly news<img src="/blog/emoji/rr_bluebutterfly-808265086887657537.webp" alt="rr_bluebutterfly" class="discord-emoji" />
*Did someone say smol?* No.. but in related tiny news the Butterfly prototyping is still full steam ahead, with the team managing to squeeze out another 0.7mm from the thickness of the trackers~! **Thats around 10% thinner**!!

## Server GUI refresh <img src="/blog/emoji/nighty_hug-1314209493747241011.webp" alt="nighty_hug" class="discord-emoji" />
Hate skiiing? I kinda like it, but not when im trying to get into VR~! Lots of work is being diligently done for the SlimeVR server to make your experience using our software a lot more simple, and easier to understand.

* First up, we are cooking our noodles to serve you the simplest and most reliable method of **automatic mounting** to replace the ski pose. It might be as easy as walking a few steps forward and backwards if the boffins at the cave can crack the code, so cross your fingers they can find the magic formula!
* Second, a lot of the art and icons that were designed as placeholders years ago are still there, so there is work being done to get custom, much clearer and understandable, **icons** for stuff like assignment locations.
* Finally, we are adding a **version switching** system in. It allows you to uninstall the current version and install a different one, including stuff like betas and release candidates. This will make it much easier to test new versions (without fiddling with zip files), as well as go back to you favourite version if you decide the new hotness isnt for you! Work in progress pics below.

These will all be part of a holistic UI revamp we are working on to reduce the friction in using SlimeVR trackers for users. Theres more in the pipe such as user presets and such, but more on that in a future update <3

## Spinny~! <img src="/blog/emoji/nighty_data-1314209491365007360.webp" alt="nighty_data" class="discord-emoji" />
The Spinny is hard at work Spinning, but we still need more user data. If you haven't already, consider sending us your tracker data! Not only will this help make the new slimes better, but it will mean the data will be made from YOU. Not literally of course, but you will be helping get trackers tuned to your personal usage data. Is that not awesome? All we need from you is BVH data recorded from the server (at least 1 hour) zipped up and posted into a google doc form and we will do the rest. There is no specific requirement for your movements, so just use VR for over an hour then send the file, ezpz.
