how's going, fellow slimes (i mean, ) <img src="/blog/emoji/nya_umu-850498715617198080.webp" alt="nya_umu" class="discord-emoji" />

**Dev Mondays-ish Update #94** has arrived!

So, first of all **we got extension cases for reviewers and developers sets!** That's very pog, we asked manufacturer to ship them first, because we wanna prepare review sets and dev sets asap 🥺 But also it's a smaller order, so should be fast! It was pretty fast, yes. Except, there is a problem, **main case and extension case transparency don't match**, see the pics attached. (Blue cases are review sets. And yes, I know they look really good 😭 It's my favorite color 😭 Sorry I can't make it available to everyone, at least not yet. The teal are the dev sets, I love them a lot too.) Anyhow, as you can see, the extensions are almost not transparent at all qwq I'm not sure what went wrong, but it's good that we had this smaller order, because I already contacted the manufacturer and they will make sure that the purple ones match the main cases exactly.

Second, we ordered **new tester board.** It was the most complex board I had to design, so I hope it works lol. But as I said before, it will be able to test slimes way faster, and also do a few additional tests (better battery power and charging testing, for example).

We also ordered a sample of the **new version of SlimeVR Main PCB** that will be used for the second batch. There are some minor changes, like improvements in silk screen, testing pads, and major changes like replacing TP4056 with TP4057 (we didn't use TP4056's features anyway), and replacing connectors with SMT versions). If all these changes are good, we'll go with this version or maybe make couple more small changes, we'll see. We need to order full second batch production until mid-April 😅

We're continuing to battle the stamp... And it's pain tbh '>\_<' Resin printing is not fun, and resin printing with flexible resin is worse. And we need it to match the curvature of the bottom of the case, and the prints keep breaking '>\_<' Anyway, we'll get there, but need a few more iterations.

Also! Since we stopped testing for now while we wait for the new tester, I added the amount of soldered but not tested main boards to <#1025118385585004544>. We're almost half-way through with them, and it should be way faster now, **we have a dedicated person now who does assembly full-time!** <img src="/blog/emoji/firPog-785701297478959104.webp" alt="firPog" class="discord-emoji" /> And he's really fast tbh! So soldering of main boards should be done soon, and then he can help with the final assembly. Yeah, we goin'~! (Stream soon, sorry qwq)

And **we're doing some assembly too**, without a stamp for now, but the progress is pretty slow, since no one works on this full-time yet, everyone is doing other tasks too. We're also making new assembly jig to improve the process.

Ah, **the box**! We're on the final stretch for the small box (sets 5+0, 5+1, 5+3). We need to figure out a few details before the design is done, and we hope to send it to the manufacturer before the end of the week. The manufacturer made a test print for us to check the colors. They aren't perfect to what we wanted, but it's really hard to match purple on the screen to purple on paper, so we might not try to do it perfectly and settle on how it is right now, which is still pretty good, in our opinion.

**Btw 0.7.0 beta is out!** Check <#1047570753001885748>. We're doing some fixes and we're working on more UI and onboarding improvements right here in the cave :3
