**Dev Mondays-ish Updates #7!** On Tuesday!

- **I made trackers to be able to work with one additional sensor - Tracker Extension!** It's a smaller tracker that can be wired to full-size tracker, doesn't have a battery, WiFi and everything else, and uses main tracker to communicate with SlimeVR. It can be used, for example, to have light and cheaper tracking for feet, by connecting tracker extensions on feet to ankle trackers. Each full-size tracker can have one tracker extension connected to it. *It's not final yet that this will be in production, but it's most likely.* If it works out, there will be a set of 5 full-size trackers + 3 tracker extensions (chest, 2 feet) available as an order option, that should be cheaper and more comfortable than just 8 full-size trackers.

- **I tested the system with feet tracking!** It works, but it requires some work on the software side. I intend to do this in the next few days, and then record a video. I also figure out that my favorite avatar in VRChat has too long legs, and is not very good for feet tracking. I'm creating my own, turns out it's really fun, but a lot of work...
