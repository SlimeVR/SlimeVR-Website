**Another thing I plan on doing is creating a public roadmap.** <img src="/blog/emoji/datanom-877905382394195988.webp" alt="datanom" class="discord-emoji" /> It won't be on Discord, probably on GitHub or the site - a place that can be linked to and that is much more friendly to find info on. For a few features I want to talk about today, I'll talk in short, stay tuned for more details and tasks on each as we go.

**Here's what will help make SlimeVR friendly!**

- **Easier Wi-Fi setup.** Trackers will be able to exchange Wi-Fi settings with each other, so you would only need to set Wi-Fi password for one of them. You will be able to do it via USB or via phone by connecting to unconfigured tracker's hotspot - no app required!
- **Interactive setup.** There will be an easy setup wizard in SlimeVR. You can run it at any time, it will make sure your trackers are connected, ask you a few questions about your setup and do a few short moves to calibrate the trackers. Even the first time should take no more than a few minutes before you're ready to go. **Autobone** - skeleton length configurator - will be part of it.
- **Easy reset.** You already can bind reset to controllers with OVR Advanced Settings, but in the future it will be part of the SlimeVR app, so you could do it more easy and with audio or visual feedback.
- **New GUI.** We've been talking about it for a while, and it's happening really soon.
- **Bug fixes.** A lot of early bad experiences of the reviewers were due to bugs in the early software (they literally used version 0.0.1! we are at 0.1.3 right now). Many have been fixed, many are yet left to fix, many will immerge in the future and will be fixed too. SlimeVR is constantly improving through the effort of myself and contributors.
