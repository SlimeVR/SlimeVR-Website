Heyo , how's going? We have a very tiring week, that's why

**Dev Mondays-ish Updates #102** is so late, but it's still here!

Let's go with some good stuff first:

As you have seen, **we're streaming assembly!** **We're actually packing assembled sets now!** I will try to update <#1025118385585004544> on Monday with all the last numbers of parts and other progress. But right now we have 1554 sets of accessories packed for first batch (out of 3589), and 100+ sets fully assembled (Core Set Whites for now). We also re-tested 1000 main boards with the new tester!

All of this is a lot of work, and there are many people working on it in the Cave, come to our streams to say hi and watch the process :3 We might take tomorrow light, though, the week has been a lot...

And yes, **the tester is working!** It's 10-20 times faster than the last one, way easier to operate, more reliable and tests more things (we already found a few broken boards that the last tester missed!) There are still a few things to tune and iron out, but we've tested 1000 main boards in-between working on it <img src="/blog/emoji/nya_umu-850498715617198080.webp" alt="nya_umu" class="discord-emoji" /> So testing is ahead of assembly.

So, what are the main problems we have right now? There are two:

* The boxes for 7- and 10-sets should be done by June 8th. So that's when we can start packing them, and it's unlikely that by that time we'll be done with assembly of the rest of the sets anyway, so it's fine.
* The BNO Modules that we need for the second batch and last 15-20% of the first one should be done by June 21st, which is definitely annoying 😬 After this we will need like 2-3 weeks to actually assemble everything for the rest of batch 1 and batch 2, so, if batch 2 is delayed more, that's why. We pressured the manufacturer, and they will try to find the space for us on the manufacturing line and maybe split the order if it will help, but with our luck I wouldn't bet on it. That said, **this will not delay shipping of what we already have!** Right now we have ~21500 main slimes sand 2200 extensions slimes, and missing ~5800 extensions for the first batch.

**We will not wait for these parts and will ship ASAP what we have!** When? It's likely we will be done in two weeks or so if we keep the pace, then maybe a week to ship everything from us to Crowd Supply, and maybe a week more to get to you, depending on where you live.

Anyhow, that's how the stuff is going. Now, a few pictures for y'all <img src="/blog/emoji/nya_umu-850498715617198080.webp" alt="nya_umu" class="discord-emoji" /> Prepare to get slime'd soon.
